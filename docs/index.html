Fast Rub ⚡

سرعت، قدرت و بهینگی در یک کتابخانه

Fast Rub یک فریم‌ورک مدرن، سریع و سبک برای ساخت ربات‌های روبیکا است. با پشتیبانی کامل از sync/async، HTTP/2، و معماری async-native. روی سخت‌افزار ضعیف (۲۵۶ مگابایت رم DDR1 با Alpine Linux) تست شده.

🚀 مراحل استفاده

  • با @BotFather یک بات بسازید.
  • توکن را کپی کنید.

نصب

pip install --upgrade fastrub

نصب - میرور رانفلر

pip install -i https://mirror-pypi.runflare.com/simple fastrub

شروع سریع

from fast_rub import Client
from fast_rub.types import Message
import asyncio

async def robot():
    bot = Client("my_bot")
    await bot.start()

    @bot.on_message()
    async def handler(msg: Message):
        await msg.reply("**Hello** from Fast Rub! ⚡")

    await bot.run()

asyncio.run(robot())
